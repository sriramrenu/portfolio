# Sriram R | Portfolio

A premium, modern developer portfolio built with **Next.js**, **Tailwind CSS v4**, and **Framer Motion**. Featuring a custom **Nebula Frost** theme and high-end glassmorphic UI.

## ✨ Features

- **Nebula Frost Theme**: A premium light-mode experience with theme-aware background animations (liquid nebula orbs) and deep frosted-glass effects.
- **Responsive Radar Chart**: A dynamic skills visualization that automatically scales for mobile, tablet, and desktop views.
- **Project Showcase**: Detailed project descriptions with direct links to GitHub repositories for live demonstrations.
- **Glassmorphism UI**: High-standard modern design using `backdrop-blur-xl` and semi-transparent surfaces.
- **Fully Responsive**: Optimized for all devices from small mobiles to large desktops.
- **SEO Optimized**: Built-in best practices for title tags, meta descriptions, and semantic HTML.

## 🛠 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Charts**: [Recharts](https://recharts.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sriramrenu/portfolio.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
